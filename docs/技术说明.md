# 技术说明

## 1. 目标与分解

输入是一张图片。输出是每个像素在每一层用哪种耗材、各区域顶面多高，以及可导入切片器的 3MF。

核心假设：一幅画里通常同时存在

- **大面积、低纹理、颜色能被现有耗材直接覆盖的区域**（天空、背景、服装、黑边）；
- **需要中间色/渐变的区域**（皮肤、云、反射、细节）。

因此不做“整幅画所有像素都用同一种层叠策略”，而是先分区：

```
像素 → 纯色区（直接耗材） 或 渐变区（局部层叠）
```

纯色区与渐变区共用基底：0..flatBaseLayers 层用基底耗材，之后到 flatLayers 才是目标纯色，顶面颜色按这段有限层数的前向模型预测；渐变区从某个指定层开始叠 5 层（LUT）或 N 层（TD），底下同样是基底。

## 2. 纯色 / 渐变分割

在 **CIELAB** 中工作：

1. 对每个像素计算到当前调色板最近色的 **CIEDE2000** 残差。
2. 用 5×5 积分图计算局部 Lab 方差 `σ = sqrt(varL + vara + varb)`。
3. 初始纯色区：`σ ≤ 平整阈值` 且 `残差 ≤ 配色残差`。
4. 形态学 close/open（3×3，边界 clamp）去掉毛刺；删除小于“纯色区最小面积”的连通块；填补小孔——但只吸收**孔内像素的颜色本来就落在最近耗材残差内**的孔。面积小但真实异色的色块（灰影、肤色、眼白）不能被翻成纯色，否则会在配色前就丢失细节。
5. 其余像素进入渐变区。

阈值可自动：默认取局部 σ 的 55 分位并夹在 [1.2, 8]；用户可手动覆盖。纯色区并不是“看起来平”就一定是纯色，必须同时满足“最近耗材能覆盖”，否则会进入层叠渐变。

## 3. 渐变配色

### 3.1 TD 浮雕（默认）

正面观看的 Beer–Lambert 模型：

```
T = 10^(−d / HD)
out = foreground × (1−T) + background × T
```

- `HD` 是正面遮盖距离（mm），默认 `HD = TD × 0.1`。
- 在线性 RGB 中逐层合成，再转回 sRGB/Lab 做 ΔE00。
- 对渐变区 Lab 采样做 k-means（默认 192 类，最多 256 类）。
- 为当前耗材建立**可达色域**：层序被限制为**连续色段**，每种耗材最多出现一段（不会 A-B-A-B）；枚举段数 1..5、各段长度，默认 5 色 × 6 层约 3 千条可达组合；更大的高度在段数/长度空间采样，单次上限约 12 万条。逐条合成 Lab。
- 每个聚类中心在色域中找最近颜色，并对额外色段施加很小的代价（优先 1–2 段，而不是 4–5 段）。每条候选都带 `distinct`（不同耗材数），多一种耗材加 0.25 ΔE 的结构代价；短配方形成低台阶，长配方形成高台阶，于是渐变区得到 HueForge 式起伏；不会出现红-蓝-红-蓝的反复交替。候选不超过 6000 条时直接全扫描；更大的色域取「Lab 欧氏近邻 512 条 + ΔE94 近邻 4096 条」的并集再按 ΔE00 精排，避免单一欧氏排序漏掉真正最优的配方；`tests/test-gamut-recall.mjs` 用全扫描 oracle 校验。
- 中性锁定是硬约束：目标彩度 < 8 且**全黑白**配方落在最优配方 +5 ΔE 内时，该色族锁定为纯中性集合；之后的邻域连贯重选（refine）、公共底层合并、高度合并都只能在纯中性候选里换，不能为了少几层边界而把彩色层加回来。超出 +5 ΔE 的暗灰（有限层数下黑白根本到不了）仍允许彩色混灰，并保留色差记录。
- 色域外的颜色不会被“假装可达”：软件记录 ΔE，在「色域」视图标红，按像素数建议缺少的 Bambu Basic 耗材，并可一键加入重算。
- 渐变区 recipe 长度 1..maxLayers 可变；纯色区仍是整块直印。

### 3.2 物理 LUT（可选，免标定）

使用 Lumina 的拓竹 PLA Basic LUT：

- `CMYW_008_5L`：White / Yellow / Magenta / Cyan，4 色，1024 组 5 层配方；
- `RYBWCMKG_008_5L_001`：8 色（Bambu Green / Black / Blue / Cyan / Magenta / Red / White / Yellow），1024 组 5 层配方；
- 校准层高 0.08 mm、线宽 0.42 mm、白色基底 10 层。

算法：

1. 对渐变区 Lab 采样做加权 k-means（默认 192 类，最多 256 类）。
2. 每个聚类中心在 LUT 的 1024 个 Lab 中匹配：先用 Lab 欧氏距离取 12 个候选，再用 CIEDE2000 选最终条目。
3. 条目 recipe 是 **top→bottom**，打印序列反转为 **bottom→top**。
4. 把像素分配给预测颜色最近的配方，迭代一次“按已分配像素重新求中心 → 重新匹配”。
5. 纯色区仍是直接耗材；渐变区从 `gradStartLayer` 开始，固定 5 层。

### 3.3 两种策略的取舍

LUT 在拓竹 PLA Basic 上有实测色卡，颜色更准、免标定，但固定 5 层 × 0.08 mm、颜色菜单固定；TD 可以用于任意耗材、能做变高浮雕，但 4–5 色时可达色域和细节有限。软件用色域视图把这种限制显式化，而不是靠预览滤镜掩盖。

### 3.4 结构平滑（物理尺寸）

网页不再用 0–4 的像素等级，而是让用户输入**最小可打印结构尺寸** `smoothMm`（默认 0.8 mm）与喷嘴线宽 `lineWidthMm`（默认 0.42 mm）。引擎按当前成品宽度换算像素半径：

`familyR = clamp(round(smoothMm / (2 × pixelSize)), 0, 8)`，`flatR = max(1, round(familyR × 0.5))`
`pixelSize = widthMm / workPixelWidth`

- 先对纯色/渐变二值 mask 做半径 `flatR` 的多数表决。
- 再对渐变 family 标签做半径 `familyR` 的多数表决（中心权重 2），合并小于物理阈值的色岛。
- 0 关闭；半径 0（当前分辨率下不足 1 像素）时不做平滑并提示。
- 同一个 0.8 mm 在 150 mm/640 px 约为 2 px，在 80 mm/600 px 约为 3 px，在 300 mm/640 px 约为 1 px；旧版固定像素半径会随成品尺寸漂移。
- 平滑发生在色族匹配之后、最终预测/3MF 之前，因此预览、高度图、逐层图和 3MF 一致；它是结构平滑，不是颜色模糊。
- 代价：颜色误差会上升；`smoothMm` 越大，小细节越容易被吃掉。若 `smoothMm < lineWidthMm`，UI 会警告小于喷嘴线宽的结构可能打不出来。
- 旧版 `smoothLevel` 参数仍保留在引擎中供旧计划/测试复现，物理参数优先。

### 3.5 层序合并（公共底层）

TD 的色族最终会做一次结构合并，避免相邻渐变色各用一套完全独立的底层：

1. 按面积从大到小贪心分组：每个色族加入目标色中心距离 ≤ `mergeDeltaE` 的最近组，并更新加权中心；不满足则新建组。0 关闭。这样不会把整条渐变链并成一个只能共享极短底层的巨组。
2. 每组取 1–2 个候选代表（最大面积色族 + 目标 L 中位色族），从代表 recipe 的底部截取长度 b 的前缀作为公共底层。
3. 对组内每个色族，只在“以该前缀开头”的 gamut 候选中选顶部后缀；要求新 ΔE ≤ 原 ΔE + mergeDeltaE，否则该 b 失败。
4. 从最长 b 向下尝试，取满足条件的最长公共底层（同长度取总误差更小者）；b≥2 才生效。
5. 合并后族 recipe 的底部完全相同，顶部可以不同；3MF 中这些底层会变成更大的连续色块，减少层内碎片。`sharedBasePercent` 统计至少共享一段底层的渐变像素占比。

代价：公共底层会限制颜色选择，平均色差会上升；阈值越大越明显。这个步骤和结构平滑是两件事：平滑合并“相邻像素标签”，层序合并合并“底层配方”。

### 3.6 线稿保护（定向替代全局矢量化）

**问题诊断。** 细线断裂不是轮廓采样精度不够，而是三件事叠加：

1. 纯色/渐变 mask 的多数表决会把 1–2 px 描边判给白纸；
2. 渐变色族的 5×5 多数表决同样会吃掉细线，只在两条线交叉/加粗处留下孤点；
3. 细线的抗锯齿颜色在色族中心之间来回跳，造成沿线的颜色碎片。

3MF 的 marching squares + Douglas–Peucker 已经在做轮廓矢量化；把整幅规划改成矢量色块，只能改善直边锯齿，不能修复“线被标签吃掉”，还会破坏马赛克/印象派的颗粒感。因此采用线稿保护，而不是全局矢量化。

**检测。** 对工作图统计：

- `pureWhite`：`L > 96` 且彩度 < 5 的像素；
- `edge`：右/下邻居的 Lab 距离平方 > 196 的像素；
- `dark`：`L < 80`；
- `stroke`：对 `dark` 像素做多源 BFS，求到最近非 dark 像素的距离；距离 1–3 px 的 dark 像素是细描边。大面积暗块只有边缘带会被算作 stroke，内部不受影响。

当白纸 > 8%、边缘 > 1.5%、stroke > 0.4%，且综合分数 ≥ 0.45 时判为线稿。照片/油画通常过不了白纸门限；没有白底的马赛克也不会触发。

**自动模式（默认）。**

1. 二值 mask 与 family 的多数表决改成**颜色双边表决**：只有 `ΔE² ≤ 11²` 的邻居才参与投票（中心像素权重 2）。白色邻居无法投掉黑线，黑线也不会被平滑成纸白。
2. `assignFamilies` 对 stroke 像素加惩罚：`d += 3.0 × max(0, predL − srcL − 10)²`。允许深色线落到比源色略暗的色族，但不允许被浅色配方抬亮。
3. stroke 像素不参与 family 平滑覆写，保留匹配后的标签。

**强模式。**

1. 在自动之上，把 `stroke && L < 55` 的像素直接放进 flatMask，按纯色直印。
2. 选色时同时限制明度、彩度和色相：中性黑线只能选中性耗材；彩色线只能选色相接近（方向余弦 ≥ 0.95）、彩度不超过 `1.25×源彩度+4` 的耗材；综合分 > 16 时放弃直印，回退到自动保护。这样避免深紫头发被高彩度蓝耗材描边。
3. 对直印 mask 膨胀 1 px（只扩进 dark 区），保证 0.4 mm 喷嘴能铺出最小线宽。
4. 直印线属于 flatMask，因此顶面等于纯色区顶高。相邻渐变区若更高，线会形成凹槽；这是有意的“刻线”效果，UI 会提示。
5. 断线桥接只连接**同色系**：两端受保护像素颜色必须相近（ΔE ≤ 12），中间像素要与笔画同色系（中性线只吸收中性像素；彩线要求色相余弦 ≥ 0.90、彩度不高于笔画约 1.6 倍、亮度不超过笔画 +60），且不覆盖已有其它耗材的纯色像素。真实肤色/填色横穿黑线时保留原色，宁可留一点缝，也不主动“重画”线条。

**代价与边界。** 强模式会增加描边耗材的层内换色；一条线若在源图里不足 1 px，仍会因物理喷嘴宽度而消失或断点。自动模式只做保护，不改直接颜色，因此色差通常不升反降（细线不再被白纸占掉）。该功能不替代矢量化导出；若以后需要 SVG 线稿，可单独做“轮廓导出”，而不是改变规划表示。

### 3.7 高度去重（去掉没有颜色收益的增高）

**问题诊断。** 有限色域下，原图的一点亮度差可能让算法给某一小片区域选择更长的配方；但最后预测色仍落在同一段色域里，相邻区域看起来完全相同，高度却差 10–20 层。这个高度是“无效浮雕”：它没有增加可见颜色，只增加打印时间和突兀凸起。

**后处理顺序。** 在以下步骤之后运行：

1. 色族匹配 + 结构平滑；
2. 层序合并（公共底层）；
3. 按用户最高高度抬升面积最大的色族；
4. **高度去重**；
5. 重新计算每个色族的顶面/实际最高层，再生成预览、3D、3MF。

顺序很重要：先抬升再去除，才能保证只有“抬升后仍与某个短配方几乎同色”的无效高度被收回，而不是简单地把所有色族都压到最短。

**合并条件。** 对每个高配方色族 f，在短配方色族 c 中寻找：

- 层数差 `len(f) − len(c) ≥ 4`；
- 预测色差 `ΔE00(pred(f), pred(c)) ≤ heightMergeDeltaE`（默认 1.5，可调 0–5，0 关闭）；
- c 的面积 ≥ f 的 75%（保护大面积主色/白底不被小岛配方压平）；
- c 对 f 自身目标色的误差不超过 `f.deltaE + threshold + 0.25`（防止为了矮而明显偏色）；
- 取满足条件里**最短**的 c；同长度取面积更大者。

满足后，f 的 recipe、分层高度、预测色全部替换为 c；重复最多 3 轮，让较长的色族也能追上后来被缩短的候选。

**物理合并。** 替换后，把 recipe 序列和预测 hex 完全相同的色族合并成一个 family：保留像素数最多的那个，其他 family 的像素计数并进去，`familyId` 重映射，`pixelCount` 清零。这样不是“列表里两条相同配方”，而是真正的单配方/单顶高；3MF 的 part 数、层内换色和 3D 预览都会随之减少。

**代价与边界。**

- 最高高度是**上限**，不是每个色族必须达到的目标；去重后实际最高点可能低于设置值，UI 会显示最高从 N 层降到 M 层。
- 阈值调得过高会把本应保留的浅色渐变合并；默认 1.5 只处理几乎同色的情况。若原图色差在 2–4 ΔE 且确实想要去掉高度，可手动提高到 2.5–4。
- 面积保护是必要的：如果只有一个小岛用短配方，大面积同色区域仍应保留自己的高度，避免整块白/黑被压平。
- 去重会改变层序合并统计（被缩短的色族不再共享原来的公共底层），所以 `sharedBasePercent` 会按最终 recipe 重新统计。

### 3.8 边缘光晕清理

**问题诊断。** 原图描边有 1–2 px 的抗锯齿混合色。它们进入 k-means 后会形成独立的“过渡色族”，在有限调色板下被配成短配方（常见黄/蓝/红），于是每层预览里黑线周围出现彩色细噪点。结构平滑会保留连续细带，层序合并/高度去重也无法判断这些过渡色不是设计意图。

**算法。**

1. 对源图 Lab 计算相邻像素梯度（平方距离 > 100，约 10 ΔE），标记强边缘；按 `edgeClean` 等级（0–3）膨胀 1–3 px 得到 `edgeMask`。
2. 如果渐变区占总像素 <20%，直接跳过（接近纯平线稿的渐变核心太小，继续排除会饿死聚类采样）。
3. `sampleGradientLab` 采样时跳过 `edgeMask` 内的像素，让 k-means 中心只来自“核心色”，不再产生过渡色族。
4. family 匹配和平滑之后，对每个 `edgeMask` 内的渐变像素逐圈向外搜索（1→radius）：
   - 同一圈里只取非边缘核心像素，或受线稿保护的描边像素；
   - 选择预测色最接近的相邻 family（Lab 平方距离，差距 <25 时取邻居更多者）；
   - 找到最近一圈有核心就停止，避免跳到更远但颜色略近的无关色族；
   - 最后做色差保护：邻居预测色与当前 family 预测色的 Lab 距离若超过当前差 +16（约 2 ΔE 余量），不替换，避免强档把模拟成画洗脏/偏色。
5. 边缘像素直接改用该 family 的完整 recipe，因此层内颜色、顶高和 3MF part 都跟邻接核心一致；不再出现独立过渡配方。受保护的深色描边本身不修改。
6. 最后重新统计 family 像素数，再进入层序合并/高度去重。

**参数与代价。**

- 0 关闭；1 默认、最温和；2 中等；3 最强，细发丝/小纹理可能被吃掉。
- 默认 1；彩色/结构细节多的图保持 1；线稿/贴纸边缘噪点明显时用 2。3 只用于极端情况。
- 排除边缘采样会减少色族数量、提升结构整体性；代价是平均 ΔE 略升（示例约 +0.3 到 +1.0）。
- 分层预览中的“细碎彩色点”会变成与相邻区域一致的整块底层，这是预期效果；判断最终颜色应看模拟成画/3D。

### 3.9 矢量化色块直印

这是为贴纸/扁平插画提供的**区域级矢量化直印**，不是 SVG 轮廓追踪：

- 在 family 平滑/边缘清理之后，逐个**空间连通分量**统计源 Lab 均值、三通道方差和物理面积（不是按整个颜色族合并统计：远端的眼睛/高光不会因为衣服面积够大而被一起直印）。
- 条件：分量面积 ≥ `1.5 × (2×线宽)²`（默认约 1.06 mm²）、颜色标准差 ≤ 15、**预测顶色**到最近耗材的 ΔE ≤ max(6, 残差阈值+2)、且直印 ΔE 不比原层叠配方差超过 3.0。
- 满足条件的分量标记为 flatMask，使用最近耗材直印；像素从 family 中移除，未被接受的分量继续 recipe 规划。
- 边缘小岛清理：把同一 family 的 8 连通分量分为“有核心”（存在 edgeMask 外的像素）和“纯边缘”。只合并纯边缘且面积小于物理阈值的小岛；有核心的红色丝带/高光/眼睛保留。合并目标为相邻最大色块或 flat 色。
- 边界归并：再建 3 px 抗锯齿带，带内像素只允许归到最近的**大区域**（面积 ≥ 线宽阈值）或 flat 色，不再归属边缘小 recipe；这一步能消除线稿轮廓外溢的零碎小色点。
- 直印区使用 `flatLayers` 顶高，因此会低于局部浮雕；3MF 中仍是普通水密 part。
- 开关默认关闭；适合贴纸/线稿/扁平插画。照片、油画、印象派开启后可能把渐变误判为平涂。

实测同类贴纸：纯色区 60.7% → 72.8%，平均 ΔE 1.98 → 1.86；第 6 层的大面积白/红/蓝块变为整块直印，首层红黄噪点显著减少。此模式与“边缘光晕清理”互补：前者消除大面积分层噪点，后者清理 1–2 px 过渡边。

### 3.10 诊断与导出网格

- 每个计划带 `diagnostics`：`fill`（填洞吸收/拒绝像素数）、`coverage`（纯色顶色层数、遮盖不足 >3 ΔE 的像素数与最大偏差）、`groups`（线条 / 纯色 / 渐变三组的像素数、平均 ΔE、最大 ΔE）。UI 的模拟视图标题会显示三组平均误差，打印计划 JSON/Markdown 也写入同一组数字。
- 导出网格只由 `exportGridFor(plan)` 决定：工作网格长边 >1280 时按 1280 导出，否则原生。3MF、打印计划摘要和导出提示都读这一个函数；发生降采样时明确写“已重新离散化”，不把预览网格当成导出真值。
- 小图全网格导出时，预览与 3MF 使用同一份逐像素材料；大图导出属于重新采样，细节以切片预览为准。

## 4. 高度与层

- 纯色区顶面：`flatLayers = round(flatTopMm / layerHeight)`。
- LUT：渐变区需要白色基底至少 `baseLayers=10` 层；`gradTop = max(flatLayers + reliefLayers, baseLayers + 5)`，`gradStart = gradTop − 5`。所以当纯色区太矮时，渐变区会自动抬高，UI 会提示。
- TD：`gradStart = max(1, flatLayers + reliefLayers − maxGradLayers)`；每个色块的 recipe 长度 1..maxGradLayers 可变，`gradTop` 取实际最长配方，`maxLayers = max(flatLayers, gradTop)`；基底厚度不足时警告。
- 也可以直接输入 `gradStartLayer`：此时 `gradTop = gradStart + 实际最长配方`，实际浮雕差由它反推；改浮雕差输入框会清除起始层/最高高度覆盖。
- 渐变最高高度（mm）可编辑：引擎按 `round(topMm / layerHeight)` 反算目标顶面层数，只作为**候选配方长度上限**。不会为了让最高点碰到这个值而抬升任何色族；实际最高点 = `gradStart + 实际最长配方`（`actualGradTopLayer`），UI 的“最高顶面”显示实际值。高度去重还可能把没有颜色收益的增高收回。
- 打印层高在 TD 模式可改（0.04/0.08/0.12/0.16 mm）；LUT 固定 0.08 mm。改打印层高时，UI 保持起始/最高物理高度，按新层高反算起始层和最大叠层数。
- 实际浮雕差 = `(实际 gradTop − flatLayers) × layerHeight`；正数凸起，负数凹陷。UI 的“最高顶面”显示实际最长配方的高度。
- 纯色区与渐变区共用基底：`flatBaseLayers = min(gradStartLayer, flatLayers − 1)`，顶色层数 `flatTopLayers = flatLayers − flatBaseLayers`（至少 1）。
- 纯色区顶面也走同一前向模型：基底视为无限厚背衬（与渐变区一致），在上面叠 `flatTopLayers` 层目标耗材再转 Lab；不再直接把耗材 HEX 当成无限厚实色。顶色层太薄、实际遮盖后与耗材色差 >3 ΔE 的纯色像素超过 5% 时，计划会给出警告（提高纯色区顶高或换更不透明的基底）。
- 纯色区从 z=0 到 `flatLayers`：0..flatBaseLayers 是基底耗材，flatBaseLayers..flatLayers 是目标纯色；渐变区 0..gradStart 是基底，随后是 recipe 层（各色块长度不同），再往上为空。
- 关闭“渐变随配方变高”后，所有渐变 recipe 强制为 maxGradLayers，渐变区变成等高色块，3MF 顶面平整。

## 5. 3MF 几何

对每一层、每种耗材生成一个 2D mask。连续层 mask 相同则合并成同一 prism。

每个 prism 的网格：

1. **Marching squares** 提取半像素等值线（4-bit 查表；鞍点按“分开对角 1”处理），得到若干闭合轮廓。
2. 按包含深度区分外轮廓/孔；孔挂到最近的父外轮廓。
3. Douglas–Peucker（ε=0.55 采样单位）简化轮廓，降低三角形数。
4. `earcut` 三角化顶/底盖（支持孔）。
5. 每个轮廓边生成垂直墙；墙的外法向由两侧 mask 采样决定。
6. 如果检测到非 2-manifold 边：先对 mask 膨胀 1 像素重试；再失败才退化为逐像素 tiling（保证水密）。

每个“耗材 × 连续层区间”是一个 **component part**；网格 Z 坐标是 `层号 × layerHeight` 的毫米值。3MF 里：

- 一个 assembly object 包含所有 parts；
- `basematerials` 按调色板顺序；
- **每个 triangle 都写 `pid="1" pindex="槽位"`**。Bambu Studio 的标准 3MF 导入只把“顶点色/面颜色”当作可解析颜色；只在 object 上写 `pindex` 会被当成纯几何，切片器于是沿用当前项目的默认 2 个耗材。面级 `pindex` 是让 Bambu 在“标准 3MF 导入颜色”窗口里识别 5 个颜色的关键。
- `Metadata/model_settings.config` 给每个 part 写 `extruder = 槽位+1`，并记录唯一实例/识别号；
- `[Content_Types].xml` 用 `Default Extension="config" ContentType="text/xml"` 声明两个 config 文件（不能用 3D model 的 Override，否则切片器会把配置当几何而报“配置无效”）。

这样 Bambu Studio / OrcaSlicer 会把它当成一个多材料对象，各 part 已带颜色/槽位。几何坐标**直接烘焙到 256 mm 板的 128,128 中心**，不依赖 `assemble` 或被切图器忽略的装配变换；`assemble` 仍保留为 0 位移以兼容原生项目。

Bambu Studio 对非 Bambu 项目 3MF 可能仍提示 **“3mf 文件配置无效，仅加载几何数据”**。这是它不加载第三方打印参数的固定提示，不是几何损坏；点确认后模型和 extruder part 会正常载入。若弹出“对象尺寸过小/是否转毫米”，选“否”；若弹出“是否组合成一个多零件对象”，选“是”。

**ZIP 压缩。** 3MF 本质是 ZIP。导出的模型 XML 用浏览器原生 `CompressionStream('deflate-raw')` 压缩，ZIP 中对应文件标记为 method 8；若环境不支持则回退到 store（method 0）。这不改变几何或切片器兼容性，但能把复杂线稿从约 29 MB 降到约 3.5 MB。压缩流程是异步的，UI 在生成期间保持进度遮罩。

**为什么不是一个水密实体？** 不同耗材在同一层并排，必须是多个 part；切片器负责并集。每个 part 已验证 watertight（trimesh），part 与 part 在颜色边界处共面接触，体积不重叠。

**悬空检查。** 规划器逐层重建占用 mask：第 0 层覆盖整幅图；之后每层只允许是上一层的子集。纯色区在 `flatLayers` 后结束、渐变配方在各自长度后结束，都没有新增面积，因此正常情况下 `supportAddedPixels = 0`。UI 的“悬空检查”显示这个结果，并会在发现新增像素时列出层号。Bambu Studio 的“浮空区域”提示通常来自它按独立 part 检查——颜色层 part 的底面在 z>0，它不会把下面的其他 part 当作支撑；实际切片时这些 part 是接触/并集的，以层占用检查和切片预览为准。

## 6. 色差统计

- 每个像素：原图 Lab vs 预测颜色 Lab 的 CIEDE2000；
- 报告平均、中位、P90、≤2/≤5/≤10 占比；
- 配方表显示目标色、预测色、ΔE 和像素数；
- “层内换色下界” = 每一层出现过的不同耗材数 − 1 的累加，不是实际换料次数，也不含擦料塔。

## 7. 标定公式

给定目标耗材色 F、底色 B、层高 h、观察到第 k 片与不透明参考条无差别：

1. 在 [0,1] 二分求 `T*`，使 `blend(B, F, T*)` 与 F 的 ΔE00 = 2（视觉 JND 近似）。
2. `d* = k × h`。
3. 由 `T* = 10^(−d*/HD)` 得 `HD = −d* / log10(T*)`。
4. `TD = 10 × HD`（正面/背面观看的常用近似）。

这里用标量 HD；真实材料是三通道不同的。要更准需要逐通道或矩阵校准（Lumina/Kromacut 的完整流程）。

## 8. 3D 预览

「3D」标签是一个无依赖的 WebGL 高度场视图：

- 从当前 plan 采样每个像素的实际顶面层数，换算成毫米；再乘以 1–16× 的“高度夸张”（只影响预览）。
- 顶点颜色取 plan.preview 的预测顶面颜色，转线性光；法线由高度场中心差分得到。
- 片元做方向光 + 环境光 + 轻微高光，模拟油画的厚涂反光；四周补深色板边，读成一块厚板而不是一张纸。
- 相机为透视 + 轨道：鼠标拖动改变 yaw/pitch，滚轮改变距离；没有外部 Three.js 依赖。
- 这是视觉近似：3D 预览把高度场做平滑着色，3MF 仍是精确的逐层阶梯 part；两者共享同一份高度/颜色 plan。

## 9. 已知误差源

- TD/HD 随批次、温度、层高、线宽、喷嘴变化；
- LUT 只在 0.08 mm / 0.42 mm / 白色基底条件下测过；
- 颜色预测基于正面漫射光，没有镜面反射/环境光模型；
- 5 层 LUT 的色域有限，渐变会有台阶感；TD 4–5 色时更明显。TD 的可达色域视图会量化显示缺口。
- TD 的连续色段限制会牺牲一点色准，换取更像真实浮雕/换色的层序；LUT 是实测配方，不受这个限制。
- TD 的浮雕高度来自配方长度；有限颜色下短/长配方在相邻色块间可能形成较碎的台阶。可关闭“渐变随配方变高”。
- 层序合并阈值越高，共享底层越多、结构越好打印，但平均色差会上升；0 关闭。
- 线稿保护自动模式依赖白底/细描边门限；没有白底的线稿可能不被识别。强模式会改判颜色并增加描边耗材的换色；1 px 以下的线仍可能因喷嘴宽度丢失。
- 3MF 的 marching squares 轮廓在半像素处，边界可能比预览偏移约 0.25–0.5 像素；
- 换色次数/耗材估算不含擦料塔、支撑、裙边/ brim，也不等于打印时间。
